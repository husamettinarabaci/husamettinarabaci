# husamettinarabaci.com (Temporary One-Page Site)

This is a minimal single-page site intended to be deployed via **GitHub Pages**.

## Deploy on GitHub Pages

1. Create a new repository (e.g. `husamettinarabaci.com`).
2. Add these files to the repo root:
   - `index.html`
   - `styles.css`
3. Push to GitHub.
4. In the repo: **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` (or `master`) / root
5. Your site will be published.

## Customize

- Replace the placeholder **LinkedIn** and **GitHub** URLs in `index.html` (search for `href="#"`).
- Email is currently set to: `info@husamettinarabaci.com`.
