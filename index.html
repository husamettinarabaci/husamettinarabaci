Inventor Work

The hexaTune framework

hexaTune is a Harmonic Field Synthesis System.

Devices built on this infrastructure operate as Harmonic Tuning Engines.

The framework provides programmable infrastructure for structured harmonic wave pattern generation across acoustic, electromagnetic, photonic, and quantum fields. It combines hardware, DSP, protocols, applications, and APIs into a single open technology ecosystem.
